# Footstep-Power-Generation-System
A renewable energy project that generates electricity from human footsteps using piezoelectric sensors.

## Project Description
This project generates electrical energy from human footsteps using piezoelectric sensors.

## Components Used
- Piezoelectric Sensors
- Bridge Rectifier
- Capacitors
- Battery
- Voltage Regulator
- LED strip

## Working
When pressure is applied to the piezoelectric sensors, electrical energy is generated. The generated AC voltage is converted into DC and stored.

## Applications
- Railway Stations
- Shopping Malls
- Smart Cities
- Public Walkways

## Results
Successfully generated electricity from footsteps and powered LEDs.
